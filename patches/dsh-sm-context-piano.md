# dsh-sm-context-piano — managed as a fork, not a patch

The piano plugin (Codex-style conversation navigator for the DeepSeek Harness
Web GUI) is **not** carried here as a patch. It is maintained as a full fork:

- Repository: [amazing-fish/dsh-sm-context-piano](https://github.com/amazing-fish/dsh-sm-context-piano)
- The fork's `master` **is** the patch: it builds on top of upstream
  `hjj345345/dsh-sm-context-piano` and adds native navigation takeover,
  semantic piano keys, single-track full history, session-probe selection, and
  DSH 0.1.7 / 0.2.0 compatibility work
- Install as a git dependency: `github:amazing-fish/dsh-sm-context-piano#master`

See the fork's own README and changelog for the feature set and the
DSH-version compatibility matrix.
